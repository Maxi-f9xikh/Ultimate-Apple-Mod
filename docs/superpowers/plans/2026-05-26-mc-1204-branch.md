# MC 1.20.4 Branch — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a `1.20.4` Git branch from `main` with all dependency versions updated to Minecraft 1.20.4 — Forge 49.2.7, Fabric Loader 0.16.13, Fabric API 0.97.3, Architectury 11.1.17.

**Architecture:** Version-bump only. 1.20.1 → 1.20.4 has no breaking Java API changes affecting this mod. All source code stays untouched; only build config and metadata files change. If the build fails after version updates, fix each compile error iteratively.

**Tech Stack:** Architectury Loom 1.10-SNAPSHOT, Forge 1.20.4-49.2.7, Fabric Loader 0.16.13, Fabric API 0.97.3+1.20.4, Architectury API 11.1.17, Java 17, Gradle 8.
